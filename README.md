# Burden-of-HIV-AIDS-and-STIs-Among-AYAs-in-BRI-2023-GBD
R scripts and Python code for analyzing the burden, epidemiological trends, socioeconomic associations, and future projections of HIV/AIDS and sexually transmitted infections among adolescents and young adults aged 10–24 years across 156 Belt and Road Initiative countries, based on the Global Burden of Disease Study 2023 (GBD 2023).
